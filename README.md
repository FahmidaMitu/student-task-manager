# Student Task Manager

A modern, responsive Student Task Manager web application built with React and Vite. This application helps students efficiently organize, track, and manage their daily academic tasks, assignments, and goals with features like real-time filtering, statistics, and conditional rendering.

## Features

- **Add New Tasks:** Easily input and add tasks to your daily list.
- **Task Completion Toggle:** Mark tasks as completed or pending with interactive checkboxes.
- **Task Filtering:** Filter tasks instantly by All, Completed, and Pending tabs.
- **Task Statistics:** Real-time summary and statistics of your overall tasks.
- **Delete Tasks:** Remove unwanted or finished tasks with a confirmation prompt.
- **Conditional Rendering:** Clean fallback UI and dynamic components based on task states.
- **Reusable Component Architecture:** Built using modular components (`Card`, `TaskForm`, `TaskList`, `TaskItem`, `TaskStats`).

## Tech Stack

- **Frontend:** React, JSX, CSS3
- **Build Tool:** Vite
- **Package Manager:** npm
- **Version Control:** Git & GitHub
